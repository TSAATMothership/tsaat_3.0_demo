## PDF and Excel actions

Every PDF and Excel action, including reused findings tables and risk-detail panels, uses one browser document controller. Existing browser Excel actions use the same pipeline. The native **Generating Document** dialog displays the document title, an animated document symbol, four stages (Load evidence, Prepare layout, Generate document, Save download) and the current operation. Numeric progress is shown only when the renderer supplies a real completed/total count; other work uses an indeterminate animation. Reduced-motion preferences disable decorative motion.

Only one document is generated at a time. Cancel or Escape aborts data loading and worker rendering without downloading an incomplete file. A failed attempt remains in an actionable dialog with Try again and Close. The modal contains keyboard focus, stacks over an existing slide-out and returns focus to the invoking control on completion/cancellation/close. Narrow and short viewports keep actions reachable. A successful download has an accessible completion announcement. Browser memory/input limits produce a clear smaller-scope message rather than silently truncating evidence.

Existing GET report bookmarks open a compact generation page retaining the full source query, where the user starts the local download. Page and panel exports retain their applied filters, selected snapshot and established filenames. This interaction does not change persona visibility, data access, or CSV-only downloads. See [browser document generation](client-document-generation.md).

## Dialogs and panels

Impact Topology opens at the normal Settings size with Filters and Layout & view minimised. Header buttons reveal/hide both groups (`aria-expanded`) and toggle a viewport-filling dialog (`aria-pressed`); Close stays available. Hidden controls retain values and leave the tab order. View toggles preserve layout, coordinates, node selection, camera and scope/date. Escape exits full screen before closing the graph, after nested menus/dialogs have handled Escape. Desktop charts consume the extra space; narrow/short windows retain vertical scrolling and focus containment. Both view states reset when the popup reopens.

The view-toggle change affects presentation, its browser smoke and these UI/feature contracts only. Select lint/types, focused graph/page tests, documentation checks and desktop/narrow/short-window keyboard browser checks. SQL/JSON data, persistence, calculations, access/scope rules, report content, dependencies and generated inventories are unaffected; no provider regression gate, SQL migration/parity, dual build, inventory regeneration or full release gate is required for this change. An isolated No-SQL build supports compiled browser verification.

Use native dialogs for focus containment and modal layering. `settings-popup` defines Settings dimensions: 150px desktop margins, 16px at the existing small-screen/short-height breakpoint. Shared asset compliance uses that class and WorkspaceTabs. Entity and finding details use the existing right-hand measure-scope panel styles. CMDB opens from the left at min(44.8rem, 76.8vw), 20% narrower than its former min(56rem, 96vw) width, with a right border/shadow and a left-entry/exit transition. Reduced motion remains supported.

Service Impact's Explore selection opens an Impact Topology using the same settings-popup class; Scope & Selection remains on the page and there is no Explore the Impact tab. Inspired by [Neo4j Bloom's graph scene](https://neo4j.com/docs/bloom-user-guide/current/bloom-visual-tour/bloom-overview/), coloured category nodes, labelled connections, a search field and a node inspector expose recorded service/system/device relationships. Risk rings and finding badges supplement category colour with text/counts. Search includes collapsed nodes, and scene limits are explicitly disclosed. Selecting a node highlights its neighbours; connection focus, system expansion, drag/pan, zoom and Fit graph support exploration without changing the analysis totals or header scope. Keyboard users can select SVG nodes with Enter/Space, pan the focused graph with arrow keys, zoom with +/−, reset with 0, and navigate connections through ordinary buttons. The inspector stacks under the graph on narrow/short viewports. Native dialog focus containment, Escape and focus return apply, including nested finding details.

Risk controls sit above the graph: a severity checklist, paired inclusive Min/Max sliders with numeric equivalents, and Reset risk filters. Counts combine the chosen severities per node. Opening the graph or resetting its filters selects Critical Exposure and High Risk with Min 1. Select all starts at Min 0; a subset starts at Min 1, which can be changed explicitly. The checklist keeps configured labels and closes on Escape before the graph does. Filtered totals/search/details update together, and empty results retain controls and a reset action. The popup opens in Hierarchical layout with Top down direction. Layout controls offer Force-Directed, four Hierarchical directions, Circular/Radial, and generated Coordinate/Spatial positions; selected spatial nodes have X/Y fields. The layout families take inspiration from [NeoDash's graph layouts](https://neo4j.com/labs/neodash/2.4/user-guide/reports/graph/) and [NVL's layout types](https://neo4j.com/docs/api/nvl/current/types/_neo4j_nvl_base.Layout.html). One animation clock moves nodes and attached edges over 650ms with eased interpolation, including interruption handling and reduced-motion support. Coordinate generation and editing are local to the popup and are explicitly distinguished from geography. Expanded controls wrap and the graph/inspector scroll vertically on narrow or short windows. The normal dialog retains Settings dimensions; full-screen mode fills the browser viewport.

Return focus to the invoking control. Escape closes a filter menu before an inner detail, then the main dialog. Include loading, error/Retry and empty states. Evidence and remediation remain available without clipped text.

## Charts

Impact Topology node selection retains camera zoom and pan for pointer/keyboard selection, search results and connected-node links. Fit graph and the 0 key explicitly reset the view. Existing layout, filter, expansion and connection-focus actions retain their scene-fitting behavior.

Compliance is green, non-compliance red and unknown orange, with visible numbers/text. Severity colors are Critical Exposure red, High Risk orange, Major yellow, Moderate blue and Data Gap purple. Summary exception lists scroll after approximately five rows and retain total compliance bars when no exceptions appear.

Device/SPI heatmaps default to 40px cells, support resizing, search and status filters, group devices by result and place the highest SPI severity at the right. Zero observations must not be presented as 100% compliance.

## Accessibility and responsive acceptance

Tabs support Arrow keys and Home/End with aria-selected/controls. Controls have labels and visible focus. Long names/evidence wrap or scroll inside their region; tables can scroll horizontally without overflowing the viewport. Verify desktop and a 390px viewport, keyboard traversal, layering, focus return and loading/error/empty states.

Shared implementation: FindingsDataTable, FilterHeader, WorkspaceTabs, SettingsPopup, ServerComplianceView, RiskEntityDetailsPanel, ComplianceHeatmap and app/globals.css. Update this contract when shared interactions change.
