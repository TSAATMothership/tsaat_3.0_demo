# TSAAT Database Model

- SQL schema: `docs/database/tsaat_schema.sql`
- ERD (Mermaid): `docs/database/tsaat_erd.mmd`

Render the ERD to SVG (optional):

```bash
npx @mermaid-js/mermaid-cli -i docs/database/tsaat_erd.mmd -o docs/database/tsaat_erd.svg
```

Render the ERD to PNG (optional):

```bash
npx @mermaid-js/mermaid-cli -i docs/database/tsaat_erd.mmd -o docs/database/tsaat_erd.png
```
