# Asset taxonomy

The canonical endpoint types remain Server, Workstation, Network Device, Storage Device, Printer Device, Other and IP Node. Their stored keys and configurable CMDB attributes remain shared across SQL and JSON. Discovery-tool applicability remains available read-only and feeds retained inventory coverage context.

SPI applicability, severity/priority matrices and indicator definitions are retired. See [data alignment](../docs/feature-retirement.md) and [CMDB fields](../docs/cmdb-asset-type-attributes.md).
