# Workspace, navigation and scope

Persona selection and configuration are available only in Menu → Settings → Personas. The sidebar has no persona dropdown. Saved preferences filter both sections and individual pages before existing scope visibility rules; drill-through links to unavailable destinations are disabled, including new-tab links and compatibility aliases. Independently configured popup switches control their buttons/chart actions. The five personas and All sections option preserve the current route, applied scope, security domains and snapshot date. Empty visibility directs users to Settings; direct URLs and APIs retain their current access. See [Personas](../docs/personas.md).

Current contract: TSAAT UI 3 baseline, 2026-11-03. Maintain with related source changes; see [SDLC](../docs/sdlc.md).

Pages and APIs open directly without user login. The header has no Signed in or Logout controls. The workspace is empty until a managed-network or ICT-system header scope is applied. The two scope types are mutually exclusive, accept multiple IDs and retain the selected snapshot date. Pending header edits are applied with Update; navigating away discards unapplied edits. Empty applied scope empties the content while retaining the active item.

Sidebar order and visibility are defined in lib/workspace-navigation.ts. Governance is first, with Trends, Cyber Terrain Insights, Installed Software Insights and Discovery Insights, in that order. Discovery Insights uses `/governance/discovery-insights`; legacy `discoveryView=overview` links redirect there with scope/date retained. Governance Overview is retired; `/governance/overview` redirects to Trends while preserving query selections, including header scope, security domains and date. Trends presents a scoped executive history of compliance, lifecycle and discovery. Insights is a scrolling [Cyber Terrain Posture executive briefing](15-Governance-Insights.md) using existing scoped Discovery and Service Impact data. Without scope the content remains empty. All three remain available under either scope kind and retain scope/date during navigation. No new API or storage contract is introduced.

Cyber Security follows Governance with Network Risk Profile then ICT System Risk Profile, followed by Service Impact Analyser, ICT System Impact Analyser and ICT System Dependencies. Discovery contains coverage and inventory explorers, with Installed Software Explorer; Installed Software Dashboard is omitted from the sidebar while its bookmarked URL remains available. Installed Software Insights is a separate Governance page directly below Cyber Terrain Insights. Topology Explorer follows Shadow IT Explorer in Discovery and uses the same scope/date. Observed Measures starts with Measures Summary, followed by Measures Trends, KPIs and SPIs. Measures Trends separates KPI/SPI history into two tabs with five date ranges. Findings contains only Findings Register; Briefs & Reports is separate. Settings is a header-menu modal. The Cyber COP overview, old posture pages, entity/SPI heatmaps, Findings Summary and Target State Analyser are not sidebar destinations.

Navigation preserves applied scope/date, displays the shared loading overlay and supports cancellation to the previous view. Risk-profile scope changes select the compatible network/system route. ICT System Impact Analyser is hidden from the sidebar whenever one or more managed networks are applied, including when it was the active view. It becomes available again with ICT-system scope or after clearing managed-network scope; pending header edits do not change visibility until Update. Retired posture and entity URLs redirect to current risk profiles/details rather than rendering the previous page design.
