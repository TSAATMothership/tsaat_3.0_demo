# TSAAT solution design

The current application has two sidebar sections. The header retains network/system selection, independent security domains and the selected snapshot date. Access remains login-free; saved personas are navigation preferences.

| Settings retirement and retained shared configuration | [Menu and Settings removal](11-Settings.md) |
| Exports | [Browser PDF/Excel contracts](../docs/client-document-generation.md) |

The old Cyber Security, Observed Measures, Findings and Briefs & Reports sections are retired. Retired numbered specifications remain as explicit compatibility/upgrade notices. Their historical behavior is available in Git, not an active product contract.
